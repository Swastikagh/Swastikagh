### 2. Explainable Lung Cancer Detection System
*Multi-class CT-scan classification (Normal / Benign / Malignant) with visual interpretability. Accepted at **IPTA 2026**.*

- Classified CT scans as Normal, Benign, or Malignant with **97.95% accuracy** using **ConvNeXt** transfer learning, applying Grad-CAM and thorough model evaluation so predictions can be interpreted and verified.
- Evaluated model performance using class-level precision and recall, applying **Grad-CAM** to visualize tumor-relevant spatial regions and support interpretable validation of diagnostic outcomes.
- Evaluated against standard CNN and Vision Transformer baselines for feature saliency and generalization stability.

`Python` `PyTorch` `ConvNeXt` `Grad-CAM` `OpenCV` `Model Evaluation`
