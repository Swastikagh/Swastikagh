## 🚀 Featured Projects

### 1. SmartClass-AI — Live Class Quality Monitor
*An end-to-end ML system that predicts the quality of live online classes and recommends actions to teachers. Aligned with UNESCO SDG 4: Quality Education.*

- Trained on **8,000+ session records** with **24+ input parameters** (attendance, quiz scores, camera usage, network quality, chat activity) and **50+ engineered features**
- Handled class imbalance with **SMOTE**; compared multiple models and reached **92% accuracy** on held-out test data
- Served via **FastAPI** (`/predict`, `/batch-predict`, `/metrics`) with **inference time under 500 ms**
- Added **AI-generated recommendations** for teachers and a dashboard for engagement and risk levels
- **Dockerized** and deployed on **Render**

`Python` `XGBoost` `LightGBM` `Random Forest` `Logistic Regression` `Scikit-learn` `Pandas` `NumPy` `FastAPI` `LangChain` `OpenAI API` `Docker` `Render`

[![Code](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)]([SMARTCLASS-GITHUB-LINK](https://github.com/Swastikagh/SmartClass-AI))

### 2. Explainable Lung Cancer Detection System
*Multi-class CT-scan classification (Normal / Benign / Malignant) with visual explanations. Research paper accepted at **IPTA 2026**.*

- Fine-tuned **ConvNeXt-Tiny** via transfer learning on the **IQ-OTH/NCCD** dataset (1,097 2D CT slices), reaching **97.95% accuracy**
- Used **Grad-CAM** to highlight the image regions that drive each prediction, supporting transparency and responsible AI in healthcare
- Applied model evaluation techniques to improve reliability
- *Research project; not a clinically deployed or approved medical tool.*

`Python` `PyTorch` `NumPy` `OpenCV` `ConvNeXt` `Grad-CAM`

[![Code](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)]([LUNG-CANCER-GITHUB-LINK](https://github.com/Swastikagh/LungCancer-Detection-ConvNeXt))
